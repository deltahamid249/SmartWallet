# تقرير إصلاح الروابط والتنقل

تم توحيد طريقة إنشاء الروابط الداخلية حتى يعمل المشروع عند وضعه داخل
مجلد فرعي في XAMPP مثل:

```text
C:\xampp\htdocs\smart-wallet
```

## الإصلاحات التي تمت

- روابط تسجيل الدخول والتسجيل والخروج تستخدم مسار المشروع تلقائيًا.
- تحويلات `Location` لا تخرج إلى جذر `htdocs`.
- شريط التنقل العام يستخدم رابط الرئيسية والخروج الصحيحين.
- روابط صفحات الإدارة تبقى داخل مجلد `admin`.
- روابط الخدمات تبقى داخل مجلد `services`.
- روابط النماذج تعود إلى الصفحة الصحيحة بعد الإرسال.
- تمت مراجعة الروابط النسبية الثابتة والتأكد من أن الملفات الهدف موجودة.

## الرابط الأساسي

بعد تشغيل Apache افتح:

```text
http://localhost/smart-wallet/
```

لا تستخدم:

```text
file:///C:/xampp/htdocs/smart-wallet/index.php
http://localhost/register.php
```

عند الحاجة إلى رابط مطلق داخل PHP استخدم:

```php
appUrl('/register.php')
```

وعند الحاجة إلى تحويل استخدم:

```php
redirectTo('/login.php');
```

بهذا تبقى الروابط صحيحة سواء كان المشروع في جذر الخادم أو داخل مجلد
فرعي.
