# شرح ملفات المحفظة الذكية

## طريقة قراءة المشروع

كل صفحة تبدأ بالجزء البرمجي الذي يجهز الجلسة ويقرأ البيانات ويتعامل مع
النموذج، ثم تأتي واجهة HTML وCSS في الجزء الأخير. هذا الترتيب يجعل دورة
الطلب واضحة:

1. تحميل الاتصال والدوال المشتركة عبر `includes/auth.php`.
2. التحقق من تسجيل الدخول والصلاحية.
3. معالجة طلب `POST` إن وجد.
4. جلب البيانات المطلوبة من قاعدة البيانات.
5. عرض واجهة HTML باللغة العربية.

## الملفات المشتركة

### `config/database.php`

ينشئ اتصال PDO بقاعدة بيانات `smart_wallet`، ويحدد UTF-8، ويجعل أخطاء
PDO استثناءات حتى لا تستمر الصفحة باتصال غير صالح. عند فشل الاتصال يعرض
رسالة عربية مختصرة بدل تسريب تفاصيل قاعدة البيانات.

### `includes/functions.php`

الدوال الموجودة هنا:

- `appBasePath`: يكتشف مجلد المشروع داخل `DOCUMENT_ROOT`.
- `appUrl`: ينشئ رابطًا داخليًا يعمل من جذر الخادم أو من مجلد فرعي.
- `redirectTo`: ينفذ تحويلًا داخليًا ثم يوقف الصفحة.
- `e`: يحمي النصوص عند عرضها في HTML.
- `csrfToken` و`verifyCsrf`: حماية النماذج من CSRF.
- `actionToken` و`consumeActionToken`: منع تكرار العمليات الحساسة.
- `flash`: رسائل مؤقتة تظهر مرة واحدة.
- `normalizeAmount` و`formatMoney` و`moneyLabel`: التحقق من المبالغ
  وتنسيقها دون فقدان الدقة.
- `cleanNote`: تنظيف ملاحظات المستخدم وقصر طولها.
- `clientIp`: قراءة عنوان IP بعد التحقق منه.
- `logAdminAction`: حفظ سجل إجراءات الإدارة.
- `createAdminNotification`: إنشاء إشعار للإدارة.
- `csrfField`: إنشاء حقل CSRF مخفي داخل النموذج.

### `includes/auth.php`

يبدأ جلسة PHP، ثم يوفر:

- `isLoggedIn` و`currentUserId`: معرفة حالة المستخدم ورقمه.
- `isSystemAdmin` و`isAdmin`: التحقق من دور مدير النظام.
- `requireLogin`: منع الوصول للصفحات دون تسجيل دخول.
- `requireAdmin`: منع الوصول للوحة الإدارة من غير المدير.
- `loginUser` و`logoutUser`: بدء الجلسة أو إنهاؤها.
- `registerGlobalNavigation`: إضافة شريط الرجوع والرئيسية والخروج
  للصفحات المحمية، مع احترام مجلد المشروع في XAMPP.

### `router.php`

موجه بسيط للخادم المدمج في PHP. يمنع المسارات الحساسة ويعيد للملفات
الموجودة كي يتعامل معها الخادم مباشرة.

## لوحة الإدارة

كل ملفات `admin/` تبدأ غالبًا بـ `requireAdmin()`، ثم تنفذ عملية القراءة
أو التحديث، وتسجل الإجراء عند الحاجة:

- `index.php`: مؤشرات لوحة الإدارة.
- `users.php` و`user.php`: قائمة المستخدمين وتفاصيل مستخدم.
- `deposits.php` و`withdrawals.php`: مراجعة طلبات الإيداع والسحب.
- `transfers.php` و`transfer.php`: مراجعة التحويلات وتفاصيل تحويل.
- `services.php` و`service.php`: إدارة الخدمات وطلبات الخدمة.
- `notifications.php`: الإشعارات الإدارية.
- `settings.php`: إعدادات الإدارة.
- `audit_logs.php`: سجل إجراءات الإدارة.

## قاعدة البيانات وواجهة API

- `database/database.sql`: النسخة الأساسية التي تستوردها في phpMyAdmin.
- `database/*.before_sync` و`*.bak`: نسخ مرجعية، وليست ملف التشغيل
  الأساسي.
- `api/index.php`: نقطة فحص بسيطة ترجع JSON وتؤكد أن API يعمل.

## قواعد التنسيق

- أربع مسافات للمسافة البادئة.
- أسماء الدوال والمتغيرات بالإنجليزية لأنها جزء من كود PHP.
- الشروحات والتعليقات الوظيفية بالعربية.
- عدم وضع بيانات الاتصال السرية داخل المستودع.
- عدم فتح PHP مباشرة من نظام الملفات؛ التشغيل يكون من Apache.
