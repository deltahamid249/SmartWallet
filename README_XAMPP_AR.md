# تشغيل المحفظة الذكية على XAMPP

هذا المشروع تطبيق PHP يعمل بواسطة Apache وقاعدة بيانات MySQL/MariaDB. لا
تفتح ملفات `.php` بالنقر المزدوج، ولا تستخدم إضافة Live Server في VS Code؛
هاتان الطريقتان تعرضان كود PHP بدل تنفيذ PHP.

## التشغيل الصحيح

1. فك الضغط عن مجلد `smart-wallet` وضعه كاملًا داخل:

   ```text
   C:\xampp\htdocs\smart-wallet
   ```

2. افتح لوحة XAMPP وشغّل:

   - Apache
   - MySQL

3. افتح phpMyAdmin من:

   ```text
   http://localhost/phpmyadmin
   ```

4. أنشئ قاعدة بيانات باسم:

   ```text
   smart_wallet
   ```

5. افتح قاعدة البيانات، ثم استورد الملف:

   ```text
   database/database.sql
   ```

   لا تستورد ملفات `*.before_sync` أو `*.bak`؛ هذه نسخ مرجعية قديمة
   للاحتفاظ بها فقط.

6. افتح النظام من الرابط التالي:

   ```text
   http://localhost/smart-wallet/
   ```

   لا تفتح:

   ```text
   file:///C:/xampp/htdocs/smart-wallet/index.php
   http://localhost:5500/index.php
   ```

## بيانات اتصال قاعدة البيانات

الإعداد الافتراضي في `config/database.php` متوافق مع XAMPP:

| الإعداد | القيمة الافتراضية |
| --- | --- |
| الخادم | `127.0.0.1` |
| المنفذ | `3306` |
| اسم القاعدة | `smart_wallet` |
| المستخدم | `root` |
| كلمة المرور | فارغة |

إذا وضعت كلمة مرور لمستخدم `root` في XAMPP، عرّف متغير البيئة
`SMART_WALLET_DB_PASS` في إعدادات Apache أو عدّل إعداد الاتصال المحلي بما
يتوافق مع إعداد جهازك.

## لماذا تمت إضافة دعم المسار؟

عند وضع المشروع داخل مجلد فرعي مثل `htdocs/smart-wallet` لا يكون
`/login.php` هو الملف الموجود داخل المشروع، بل يبحث Apache عنه في جذر
`htdocs`. أضيفت الدوال `appBasePath()` و`appUrl()` و`redirectTo()` في
`includes/functions.php` لتكوين الرابط الصحيح تلقائيًا، من غير تغيير
منطق الإيداع أو السحب أو التحويل أو الصلاحيات.

## إذا ظهر كود PHP في المتصفح

تحقق بالترتيب التالي:

1. تأكد أن شريط Apache في XAMPP لونه أخضر وأن المنفذ 80 أو 443 غير مستخدم
   من برنامج آخر.
2. استخدم الرابط `http://localhost/smart-wallet/` وليس مسار الملف المحلي.
3. جرّب إنشاء ملف اختبار PHP بسيط في `htdocs` يحتوي على
   `<?php phpinfo(); ?>` وفتحه عبر `http://localhost/test.php`.
4. إذا ظهر نص PHP نفسه، أعد تشغيل Apache وتحقق من تثبيت PHP ضمن XAMPP؛
   المشكلة في إعداد Apache وليست في ملفات المحفظة.
5. إذا ظهرت رسالة قاعدة البيانات، فهذا يعني أن PHP يعمل وأن المطلوب هو
   استيراد `database/database.sql` أو تصحيح بيانات الاتصال.

## ترتيب المشروع

```text
smart-wallet/
├── index.php                 الصفحة الرئيسية بعد تسجيل الدخول
├── login.php                 تسجيل الدخول
├── register.php              إنشاء حساب
├── deposit.php               الإيداع
├── withdraw.php              السحب
├── transfer.php              التحويل بين المستخدمين
├── transactions.php          سجل العمليات
├── payments.php              المدفوعات
├── services/                 خدمات الاتصالات والفواتير
├── admin/                    صفحات لوحة الإدارة
├── includes/                 الجلسات، الصلاحيات، والدوال المشتركة
├── config/                   إعداد الاتصال بقاعدة البيانات
├── database/                 مخطط قاعدة البيانات
└── docs/                     الشرح العربي التفصيلي
```

يوجد شرح الملفات والدوال في `docs/شرح_الملفات_AR.md`، وتفاصيل إصلاح
الروابط والتنقل في `docs/تقرير_إصلاح_الروابط_AR.md`.
